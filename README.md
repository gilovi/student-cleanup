# student-cleanup

אפליקציית דפדפן לפיצול קובץ אנשי קשר (`.vcf`) של תלמידים: כל מספר טלפון הופך לאיש קשר נפרד.

## כללי השמות
- טלפון של הורה: `<שם>-אבא` / `<שם>-אמא`. מספר משותף לשני ההורים: `<שם>-אבא\אמא`.
- טלפון ראשי שזהה למספר של הורה: נשמר פעם אחת, בשם של ההורה.
- טלפון ראשי שונה, ורק הורה אחד רשום: מקבל את ההורה השני עם `?` (למשל `-אמא?`).
- טלפון ראשי שונה ואין הורים רשומים: `-אבא\אמא?`.
- טלפון ראשי שונה ושני ההורים רשומים: נשאר עם השם בלי תיאור.
- טלפון בית: `<שם>-בית`. שדות ריקים מושמטים.

הכל רץ בדפדפן, הקובץ לא נשלח לשום שרת.

## פקודות
```bash
npm install
npm run dev        # שרת פיתוח
npm run build      # בנייה ל-dist/
npm test
npm run typecheck
npm run lint
```
